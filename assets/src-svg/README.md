# Illustration sources

Standalone, editable copies of the big inline illustrations in `index.html`.
These files are NOT loaded by the page — after editing one, paste the updated
markup back into the matching `<svg>` block in `index.html`.

Palette: teal `#0D9488` / `#0B7268`, amber `#F59E0B`, ink `#123832`,
soft teals `#CCF1EA` `#BFE7DC` `#8FD0BF` `#9AD8C6`, sky `#E8F6F1`,
sand `#FDE9C8`, coral `#F97362`, skin tones `#C68B59` `#8C5A33`.
